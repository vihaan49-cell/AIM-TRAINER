# AIM-TRAINER
🎯 Aim Trainer — Pygame Project

Aim Trainer is a fun and interactive Python project built using Pygame, designed to help improve reaction time and aiming accuracy. Targets appear randomly on the screen and grow/shrink visually, making timing essential.

🚀 Features

Smooth target animation (grow and shrink)

Random target spawning

Fully animated multi-ring target design

Adjustable spawn speed and target size

Clean and simple Pygame loop structure

🖥️ Requirements
Install dependencies

Make sure you have Python and Pygame installed:

pip install pygame

📦 Project Setup & Run

Clone/download the project, navigate to the folder, and run:

python main.py

🕹️ How It Works

A new target appears every 400ms at a random location

Targets animate by expanding and contracting

You can modify behavior such as speed, size, and colors from within the Target class
